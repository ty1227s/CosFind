CosFind 管理画面 キーボードショートカット
=========================================

ブラウザ標準ショートカットと競合しない割り当てです。
単独文字キーは使用しません。Altキーを押しながら操作してください。

Alt + N            現在表示中のタブで新規登録画面を開く
Enter              編集中の内容を保存する（テキストエリアでは改行）
Alt + /            管理画面内の検索欄へ移動し、現在の文字を選択する
Alt + 1            ブランド管理タブへ移動
Alt + 2            チェーン管理タブへ移動
Alt + 3            商品・カラー管理タブへ移動
Alt + 4            店舗管理タブへ移動
Esc                編集画面またはショートカット一覧を閉じる
Alt + K            ショートカット一覧を表示・非表示
Tab                次の入力項目へ移動
Shift + Tab        前の入力項目へ移動

画面上の表記
------------
新規登録（Alt+N）
保存する（Enter）
ブランド（Alt+1） / チェーン（Alt+2） / 商品・カラー（Alt+3） / 店舗（Alt+4）
検索欄（Alt+/）
閉じる（Esc）
ショートカット（Alt+K）

注意事項
--------
- Chrome等のブラウザで使われる Ctrl+N、Ctrl+S、Ctrl+F は使用しません。
- Alt+1〜4とAlt+Nは編集中には動作しません。入力内容の誤消失を防ぐためです。
- 削除にはショートカットを割り当てていません。誤削除防止のため、画面上の削除ボタンと確認画面を使用してください。
